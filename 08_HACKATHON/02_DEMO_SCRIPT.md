# Hackathon Demo Script

## Opening

"Most blockers ask you to fight your phone. We built one that asks you to talk to a person."

## Scenario

"I've already opened Instagram several times. The system sees the pattern locally. It doesn't assume every opening is bad, but this one looks like a habit loop."

Show intervention.

## Friend interaction

"Instead of a PIN or a permanent accountability controller, my friend is a social escape route."

Show friend notification.

## Technical moment

"The friend isn't sending an unlock command. Both devices have cryptographic identities. The reset session is authenticated, and the final unlock grant is short-lived and bound to this device, this session, and this app rule."

Show diagnostics/session details.

## Closing

"The phone still enforces the block locally. The server only coordinates the two devices. AI helps decide how much friction to introduce; it never gets to override the security policy."
