# Competitive Context

The broad category of social accountability app blockers is already populated. Existing products in this space include friend-pairing/approval blockers, timed focus apps with accountability, partner-controlled screen-time systems and social screen-time trackers.

Therefore the implementation must not present these as unique:

- app blocking;
- friend approval;
- QR pairing;
- temporary unlock codes;
- accountability partners;
- schedules;
- screen-time statistics.

The distinctive engineering story is the combined system:

`habit detection -> adaptive intervention -> human social substitution -> authenticated reset session -> cryptographic proof -> short-lived local unlock`

The project should compete on technical integration and product quality, not on claiming basic accountability as a new invention.
