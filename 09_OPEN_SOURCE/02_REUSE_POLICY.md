# Open-Source Reuse Policy

## Allowed by default

- studying architecture;
- reimplementing behavior from public documentation;
- using compatible MIT/Apache-2.0 code after license review;
- using standard AndroidX libraries.

## Requires explicit decision

- GPL/LGPL components;
- code with unclear license;
- copying large portions of a repository;
- vendoring proprietary SDKs.

## Third-party notices

Create `THIRD_PARTY_NOTICES.md` in the final app repository. Include name, URL, version/commit and license.
