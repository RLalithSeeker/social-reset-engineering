# Open Technical Questions

These are implementation experiments, not reasons to stop the project.

1. Which exact Android key provider/algorithm combination is most portable across the target hackathon devices?
2. How consistent is AccessibilityService foreground detection on the target iQOO model?
3. Can the target devices support the intended call lifecycle observation? If not, use FriendAcceptedVerifier.
4. Which push transport is most convenient for the demo: FCM or a foreground WebSocket relay?
5. Is on-device Prompt API available on the exact demo phone? If not, keep rule-based classifier.
6. Does the target OEM impose additional battery restrictions?
7. Does the final distribution target permit the chosen enforcement mechanism and permissions?

All answers must be recorded here when tested.
